# Parking a running session asks whether to end it too

Press w (or Park) on a session that runs in a terminal of the window, and a dialog asks: End session and park, or Park, keep it running. A parked session that was ended takes no resources, and you resume it from its row; it stays parked.

When the session waits for your next prompt, Enter ends and parks it at once. When it is working, asking you something, or skydeck cannot tell, the dialog starts on keeping it running. A letter typed while the dialog asks puts it on Cancel.
