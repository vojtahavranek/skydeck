# A shell under a session's terminal

Press Ctrl+Shift+S, or `Shell` in the session's header, to open a shell under
the selected session's terminal, in the session's folder: read what Claude Code
asks you to run above, and type it below.

Ctrl+Shift+S again hides it. What runs in it keeps running, and a dot beside
`Shell` says that it is there. Drag the bar between the two to change its
height. The shell ends with `exit`, and when its session ends.
