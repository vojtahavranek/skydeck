# skydeck has a version number

skydeck now names its versions with a number like `0.9.16`, in place of a commit id alone. You
see it in `skydeck --version` and the first line of `skydeck doctor`, in Settings under Updates,
and in the update dialog and `skydeck update`, which name the version you have and the one an
update brings (`0.9.16 → 0.9.19`).

The last number goes up by one with every change that is merged. The first two are changed by
hand, rarely.
