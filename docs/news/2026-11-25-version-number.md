# skydeck has a version number

skydeck now has a version like `0.9.16`. You see it in `skydeck --version` and the first line of
`skydeck doctor`, in Settings under Updates, and in the update dialog and `skydeck update`, which
name the version you have and the one an update brings (`0.9.16 → 0.10.0`).

A change you can see raises the second number; a fix raises the third.
