# Web addresses in Claude Code's replies stand out

A web address in a reply used to look like the text around it. It is now drawn in blue as a link;
Ctrl+click opens it, as before. A link with its own text shows that text alone, and the first
Ctrl+click shows where it leads. To have plain text again, set `Web addresses in replies` to
`As plain text` in Settings: sessions started after that show addresses as before. If you set
`FORCE_HYPERLINK` yourself, skydeck leaves it.
